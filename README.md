# Alien Plugins

A repository for [Alien](https://github.com/iss4cf0ng/Alien) plugins.

# Disclaimer

Alien is developed for cybersecurity research, education, and authorized penetration testing only.

Do **NOT** use this project against systems without explicit authorization.

The author is not responsible for any misuse or damage caused by this software.

# Modules

## InfoSpyder

Extracts system information and detects the environment of a compromised server.

## Manager

Provides management tools for remote administration.

## Misc

Includes a variety of miscellaneous plugins.

## Post-Exploitation

Modules designed to perform post-exploitation activities.

## Privilege-Escalation

This category provides plugins to perform privilege escalation.
